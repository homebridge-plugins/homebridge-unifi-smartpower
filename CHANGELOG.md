# Changelog

All notable changes to this project will be documented in this file. This project uses [Semantic Versioning](https://semver.org/)

## [2.4.0](https://github.com/homebridge-plugins/homebridge-unifi-smartpower/releases/tag/v2.4.0) (2026-08-27)

### What's Changed

- Add official support for Node.js 24 (Active LTS) and Node.js 26 (Current)
- Drop Node.js 20 (end-of-life April 2026); Homebridge now requires Node 22+
- Align `engines` with current Homebridge verified-plugin convention: `^22.12.0 || ^24.0.0 || ^26.0.0`
- Update `cache-manager`, `cacheable`, and `keyv` to current majors
- Register accessories under the scoped package name `@homebridge-plugins/homebridge-unifi-smartpower`
- Fix PoE capability check using the correct `8023BT` flag
- Include compiled `dist/` in the published package
